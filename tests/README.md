# 🧪 MazeChase Tests

Utility scripts for testing the MazeChase game.

> **Note**: The AI testing system (EMMSOAI) has been moved to `/EMMSOAI/`.
> See [EMMSOAI README](../EMMSOAI/README.md) for the self-improving AI loop.

## Available Scripts

### debug-ws.js

WebSocket debugging utility for testing real-time connections.

```bash
node debug-ws.js
```

### test-bots.js

Bot testing for multiplayer scenarios.

```bash
node test-bots.js
```

### test-game.js

Game logic unit tests.

```bash
node test-game.js
```

### workflow.py

Python workflow automation for CI/CD.

```bash
python workflow.py
```

## Screenshots

The `screenshots/` folder contains captured game states for visual regression testing.
